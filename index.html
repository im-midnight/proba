Quelle loi pour quel problème ?

Binomiale, Poisson, exponentielle, uniforme : les critères pour choisir, la façon de modéliser, et un simulateur pour chaque loi.

Trois questions pour décider

  1. Je compte ou je mesure ? Un nombre entier (0, 1, 2…) donne une loi discrète. Une durée ou une longueur donne une loi continue.
  2. Discrète : le nombre d'essais n est-il fixé ? Oui : binomiale. Non, on compte des événements dans un intervalle de temps ou d'espace : Poisson.
  3. Continue : y a-t-il une zone privilégiée ? Aucune, tout l'intervalle est équiprobable : uniforme. C'est un temps d'attente sans mémoire : exponentielle.

Modéliser, étape par étape

  1. Définir X avec précision : « X = nombre de … » ou « X = temps avant … ».
  2. Vérifier les critères de la loi (indépendance, p ou taux constant).
  3. Estimer les paramètres : p̂ = fréquence des succès, λ̂ = moyenne observée (Poisson), λ̂ = 1/moyenne (exponentielle), a = min et b = max (uniforme).
  4. Calculer les probabilités demandées.
  5. Valider avec les données : moyenne ≈ variance pour Poisson, test du χ² d'adéquation.

Liens entre les lois

  • B(n, p) ≈ P(np) quand n est grand et p petit (n ≥ 30, p ≤ 0,1, np ≤ 10).
  • Si le nombre d'événements suit une loi de Poisson de taux λ, le temps entre deux événements suit E(λ).

Loi binomiale B(n, p)

On répète n fois la même épreuve à deux issues et on compte les succès.

Critères

  • n fixé à l'avance
  • deux issues : succès ou échec
  • p constant
  • épreuves indépendantes (avec remise, ou population très grande devant n)

Formules

P(X=k) = C(n,k) · pk · (1−p)n−k
E(X) = np
V(X) = np(1−p)

Exemple

On contrôle 20 pièces, chacune est défectueuse avec une probabilité de 3 %. X = nombre de pièces défectueuses, donc X ~ B(20 ; 0,03).
P(X=0) = 0,9720 ≈ 0,544 et P(X ≥ 1) = 1 − 0,544 ≈ 0,456.

Simulateur

from scipy.stats import binom
binom.pmf(6, 20, 0.3)   # P(X = 6)
binom.cdf(6, 20, 0.3)   # P(X ≤ 6)

Loi de Poisson P(λ)

On compte des événements, souvent rares, dans un intervalle de temps, de longueur ou de surface.

Critères

  • événements indépendants
  • taux moyen constant
  • pas deux événements au même instant
  • pas de maximum naturel : on ne connaît pas n

Formules

P(X=k) = e−λ · λk / k!
E(X) = V(X) = λ
Taux de 3 par heure : λ = 6 pour 2 heures.

Exemple

Un serveur reçoit en moyenne 2 requêtes par seconde. X = nombre de requêtes en 1 s, donc X ~ P(2).
P(X=0) = e−2 ≈ 0,135. Sur 3 secondes, λ = 6.

Simulateur

from scipy.stats import poisson
poisson.pmf(5, 4)   # P(X = 5) avec λ = 4
poisson.cdf(5, 4)   # P(X ≤ 5)

Loi exponentielle E(λ)

Le temps d'attente avant le prochain événement, ou la durée de vie d'un objet qui ne s'use pas.

Critères

  • variable continue positive
  • sans mémoire : P(X > s+t | X > s) = P(X > t)
  • temps entre deux événements d'un processus de Poisson de taux λ
  • à éviter si l'objet vieillit (usure)

Formules

f(x) = λe−λx pour x ≥ 0
F(x) = 1 − e−λx
P(X > x) = e−λx
E(X) = 1/λ, V(X) = 1/λ²

Exemple

Un composant a une durée de vie moyenne de 1000 h, donc λ = 0,001 et X ~ E(0,001).
P(X > 500) = e−0,5 ≈ 0,607. Sans mémoire : s'il a déjà tenu 1000 h, la probabilité de tenir 500 h de plus est toujours 0,607.

Simulateur

from scipy.stats import expon
expon.cdf(3, scale=1/0.5)   # P(X ≤ 3) avec λ = 0.5 (scale = 1/λ)

Loi uniforme continue U[a, b]

Une valeur tombe au hasard dans [a, b], sans zone privilégiée.

Critères

  • bornes a et b connues
  • probabilité proportionnelle à la longueur de l'intervalle

Formules

f(x) = 1/(b−a) sur [a, b]
F(x) = (x−a)/(b−a)
E(X) = (a+b)/2, V(X) = (b−a)²/12

Exemple

Un métro passe toutes les 10 minutes et tu arrives au hasard : X ~ U[0 ; 10].
P(X ≤ 3) = 0,3 et E(X) = 5 min. C'est aussi le principe de random().

Simulateur

from scipy.stats import uniform
uniform.cdf(7, loc=0, scale=10)   # loc = a, scale = b − a
